# 10 — Environment Variables

Status: **Implemented.** The API validates its environment at startup (`apps/api/src/config/env.ts`) and exits with a list of invalid variable names (never values). Secrets are supplied by the environment/secret manager, never committed (`.env*` is git-ignored except `.env.example`).

### Two-factor authentication (TOTP) — optional until the client sets policy

| Variable               | Default                      | Notes                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| ---------------------- | ---------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `MFA_ENCRYPTION_KEY`   | unset                        | 32 random bytes, base64 (`openssl rand -base64 32`). **Secret.** Encrypts TOTP secrets (AES-256-GCM). Without it MFA is unavailable (enrol returns 503). Losing it makes enrolled secrets unreadable: back it up in the secret manager; rotating it requires re-enrolment.                                                                                                                                                                              |
| `MFA_REQUIRED_ROLES`   | unset                        | Comma-separated role keys, or `NONE`. **Unset: development = nobody; production = the recommended roles (owner, practice administrator, dentist, billing administrator).** In production the list must include `ORGANISATION_OWNER`, and `NONE` is refused unless `MFA_ALLOW_UNENFORCED=true` (an explicit, logged client decision). Requires `MFA_ENCRYPTION_KEY`. Un-enrolled users of these roles are limited to enrolment; they cannot disable MFA. |
| `MFA_ALLOW_UNENFORCED` | `false`                      | Only meaningful with `MFA_REQUIRED_ROLES=NONE` in production.                                                                                                                                                                                                                                                                                                                                                                                           |
| `MFA_ISSUER`           | `MultiDentalPractice System` | Label shown in authenticator apps                                                                                                                                                                                                                                                                                                                                                                                                                       |

### Object storage (imaging) — optional; leave all unset to disable imaging

| Variable                                                                                 | Default     | Notes                                                                                                                                                                      |
| ---------------------------------------------------------------------------------------- | ----------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `STORAGE_BUCKET`, `STORAGE_REGION`, `STORAGE_ACCESS_KEY_ID`, `STORAGE_SECRET_ACCESS_KEY` | unset       | Must be set together or the API refuses to start. Secrets. Bucket must be **private** with provider encryption at rest. Region/provider are an open client decision (Q18). |
| `STORAGE_ENDPOINT`                                                                       | AWS default | For S3-compatible providers (MinIO, etc.). ★ must be `https://` in production                                                                                              |
| `STORAGE_FORCE_PATH_STYLE`                                                               | `false`     | Needed by some S3-compatible servers                                                                                                                                       |
| `IMAGING_MAX_BYTES`                                                                      | `25000000`  | Per-file upload limit (files are buffered in memory up to this size)                                                                                                       |

Without storage, upload endpoints return `503` and `/health/ready` reports `storage: not_configured` (informational; the API stays ready).

### Malware scanner (ClamAV `clamd` protocol)

| Variable               | Default | Notes                                                                                                                                                                                                             |
| ---------------------- | ------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `SCANNER_HOST`         | unset   | Host of a clamd instance on a **private** network (the protocol has no authentication or encryption). **Unset = no scanner: every upload stays quarantined and unavailable (fail closed); the API still starts.** |
| `SCANNER_PORT`         | `3310`  |                                                                                                                                                                                                                   |
| `SCANNER_TIMEOUT_MS`   | `15000` | A scan that does not finish in time is a failure (file stays unavailable)                                                                                                                                         |
| `SCANNER_MAX_ATTEMPTS` | `10`    | Failed attempts before the automatic retry job stops (an operator can still re-scan)                                                                                                                              |

Set clamd's `StreamMaxLength` to at least `IMAGING_MAX_BYTES`. `/api/v1/health/ready` reports `scanner: up | down | not_configured` (informational).

CLI-only: `DPMS_BOOTSTRAP_PASSWORD` (see docs/09). Import tool: see docs/16. Tests: `TEST_DATABASE_URL`, `SHADOW_DATABASE_URL` (migration validation).
